## Обо мне

Я учусь на специальности «Прикладная информатика» факультета прикладной математики и информатики. Учебная программа охватывает математический фундамент, алгоритмы, системное программирование, сети, Web- и мобильную разработку, анализ данных и искусственный интеллект. В проектах развиваю понимание того, как взаимодействуют структуры данных, логика приложения, интерфейсы и среда выполнения.

- **Алгоритмы и численные методы** — интерполяция, сплайны, структуры данных, алгоритмы на графах, растеризация, отсечение и 3D-преобразования.
- **Настольные приложения** — C++/Qt Widgets, Windows API для работы с процессами и Java Swing.
- **Web-разработка** — HTML, CSS, JavaScript, Node.js/Express, React и TypeScript.
- **Системы и сети** — лабораторные по ОС, сокеты/RMI, сетевые приложения Linux и многопоточность.
- **Данные и интеллектуальные системы** — исследовательский анализ данных, регрессия, учебные работы по машинному обучению и распознаванию образов.
- **Backend и инфраструктура** — прототипы на Python/FastAPI и среды разработки на Docker.
