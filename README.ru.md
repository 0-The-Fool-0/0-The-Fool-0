## Мой учебный путь

Я учусь на специальности «Прикладная информатика» факультета прикладной математики и информатики. Этот профиль отражает процесс обучения: лабораторные, эксперименты, отладку, незавершённые идеи и постепенные улучшения, а не только законченные проекты.

В учебную программу входят основы программирования, алгоритмы и структуры данных, методы вычислений, компьютерная графика, настольная и веб-разработка, операционные системы, сети, базы данных, анализ данных и сервисная архитектура.

## Текущий фокус

- **C++ и алгоритмы:** структуры данных, вычислительные методы, графические приложения и задания по операционным системам.
- **Веб-разработка:** JavaScript, TypeScript, Node.js, Express, REST API и клиент-серверные приложения.
- **Базы данных:** моделирование данных и SQL параллельно с университетскими дисциплинами.
- **Go:** изучаю язык для будущего курсового проекта по сервис-ориентированным системам.
- **Облака и инфраструктура:** сервисная архитектура, автоматизация, контейнеры и распределённые вычисления.

## Командный проект

- [MTS Cloud PC P2P](https://github.com/0-The-Fool-0/mts-cloud-pc-p2p) — хакатонный MVP команды с backend на FastAPI, frontend на React, агентами хоста/узла и Docker-средой разработки. Аутентификация, трансляция рабочего стола и аренда пока демонстрационные или не завершены. Доступная история исходного репозитория не подтверждает мой индивидуальный вклад в реализацию, поэтому я не приписываю его себе.

## Примечания

Часть рабочих репозиториев пока оформляется отдельно: проверяются лицензии наборов данных, учётные данные и настройки безопасности. Цель профиля — показать честную историю обучения, не раскрывая личные данные и материалы, которые нельзя распространять.
