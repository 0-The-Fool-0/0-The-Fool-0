# Прикладная информатика — карта учебной программы

[English version](STUDY_PROGRAM.md)

Документ систематизирует дисциплины из предоставленной ведомости факультета прикладной математики и информатики по специальности «Прикладная информатика». Названия предметов сохранены по ведомости; оформление нормализовано для удобства чтения. Оценки, персональные идентификаторы и результаты сессий не включены.

## Основные тематические блоки

- **Математика и формальные основы:** аналитическая геометрия, математический анализ, алгебра и теория чисел, дискретная математика и логика, теория графов, теория вероятностей и статистика, дифференциальные уравнения, методы вычислений, оптимизация, комбинаторика и математическое моделирование.
- **Программирование:** методология программирования, машинно-ориентированное программирование, АиСД, промышленное программирование, кроссплатформенные приложения и компьютерная графика.
- **Системы и инфраструктура:** ОС, компьютерные сети, сетевые приложения в Linux, мобильные и встраиваемые системы, распределённые и параллельные системы, информационная безопасность, RFID и обработка видеопотоков.
- **Разработка приложений:** Web и мобильная разработка, сервис-ориентированные системы, тестирование и качество, модели данных и СУБД, бизнес-процессы.
- **Данные и ИИ:** анализ и визуализация данных, машинное обучение для промышленного IoT, искусственный интеллект, распознавание образов, вычислительная лингвистика и комбинаторные методы анализа.
- **Общий контекст:** английский, русский как иностранный, белорусский профессиональный язык, история, право, философия, политэкономия, педагогика и психология, физкультура.

Группировка выше — интерпретация названий дисциплин, а не отдельная официальная классификация программы.

Следующее сопоставление — редакционная оценка по структуре репозиториев и исходникам, не официальное соответствие кафедры.

| Тема программы | Связанная коллекция / проект |
|---|---|
| АиСД | Лабораторные C++ первого семестра; отдельная коллекция АиСД ожидает исправления имени репозитория. |
| Методы вычислений | Приватная коллекция численных методов и интерполяции. |
| Компьютерная графика | Python-демонстрации растеризации, отсечения и 3D-преобразований; также упражнения по Qt. |
| Операционные системы | Публичный репозиторий Operating-systems с лабораторными по процессам, потокам, очередям и клиент-серверному взаимодействию. |
| Web-программирование | Публичная лабораторная № 9 и приватная коллекция Web Programming 2. |
| Сетевое программирование | Приватная коллекция Java socket/RMI. |
| Настольные приложения | Приватные коллекции Qt Widgets и Java Swing. |
| Анализ данных | Streamlit-проект поддерживается отдельно и не представлен как завершённая витрина. |
| Cloud / распределённые прототипы | Приватный MTS Cloud PC fork — эксперимент, а не production-сервис. |
